This module adds the possibility to define a sequence for the expense
report's reference. This reference is then set as default when you
create a new expense report, using the defined sequence.

The number is also propagated as the reference of the journal entries
generated by the expense report:

- Expenses paid by the employee: the number is set on the vendor bill's
  *Reference* and *Payment Reference*.
- Expenses paid by the company: the number is set on the *Memo* of each
  payment and on the *Reference* of its journal entry.

As *Reference* is stored on every journal item, the accounts payable can
be searched, grouped and reconciled by expense report number.

Journal entries created before installing this module keep their
original reference.
