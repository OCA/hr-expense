This module adds the possibility to define a sequence for the expense
report's reference. This reference is then set as default when you
create a new expense report, using the defined sequence.

The number is also prefixed to the reference of the journal entries
generated by the expense report:

- Expenses paid by the employee: `EX0001 - Client visit` on the vendor
  bill's *Reference* and *Payment Reference*.
- Expenses paid by the company: `EX0001 - Flight` on the *Memo* of each
  payment and on the *Reference* of its journal entry.

The number is a prefix rather than a replacement, so the reference the
entries already carried is kept — which matters for company-paid
reports, where each expense line gets its own payment.

As *Reference* is stored on every journal item, the accounts payable can
be searched, grouped and sorted by expense report number, and sorting by
reference groups the items of a same report together.

Journal entries created before installing this module keep their
original reference.
