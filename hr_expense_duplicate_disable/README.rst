This module allows to disable the duplicate expense detection in
hr.expense.

When enabled, it will skip computing duplicate expense warnings,
improving performance for large expense datasets where duplicate
detection is not needed.

**Table of contents**

.. contents::
   :local:

Configuration
=============

To disable the duplicate expense detection:

#. Go to Expenses > Configuration > Settings. #. Check **Duplicate
Detection** and Save.
